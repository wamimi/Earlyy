## Working interactions

Qualifying activity, cutoff date, reward type and delivery controls set a campaign brief. Selecting products suggests shipping; cash rewards suggest a payout. The user can adjust delivery. The modal collects a brand/community name and offer details, and downloads a Markdown brief locally. It does not publish a campaign, send data, or promise that a source integration is available.
