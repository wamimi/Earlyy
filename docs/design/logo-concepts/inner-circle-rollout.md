# Inner Circle rollout

## App assets

The production symbol and wordmark are outlined SVGs, with matching inline artwork in `src/components/early-logo.tsx`. No font download is required to render the logo. Icon PNG exports are generated from the SVG. `public/early-logo.svg` remains a compatible icon for existing consumers. Shared headers and footers use the new lockup, metadata uses the new icons, and Privy uses the horizontal lockup.
